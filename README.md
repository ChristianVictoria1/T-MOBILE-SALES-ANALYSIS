# T-Mobile Retail Sales Analysis

## Overview
This project is based on real in-store retail interactions that I observed and recorded while working with customers, which I then queried using SQL to identify patterns in conversion rates, engagement levels, upselling behavior, and shift performance.

---

## Business Questions

- Which customer intent converts best?
- Does engagement level affect sales conversion?
- Which shift period performs best?
- Which interactions create the most upsell opportunities?

---

## Tools Used

- SQL
- Power BI
- Excel / CSV

---

## Key Findings

- Buy-intent customers had the highest conversion rates.
- Browse interactions converted surprisingly well.
- High engagement strongly improved sales conversion.
- The 6–8 shift had the best conversion rate.
- New purchases generated the highest accessory upsells.
